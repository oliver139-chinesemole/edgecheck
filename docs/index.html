Four Tabs

Everything in one place

No API keys needed on first run. All four tabs are populated from committed seed data so the app works immediately on a fresh clone.

📊

Smart Money

Institutional 13F holdings, insider trades, and congressional disclosures with quarter-over-quarter deltas and consensus signals. Data lag warnings are always visible.

🔬

Strategy & Backtest

Leakage-free walk-forward backtest with triple-barrier labeling, realistic round-trip costs, and an equity curve benchmarked against buy-and-hold SPY. Trains and freezes the model.

📈

Live Paper Sim

Runs the frozen model forward on seed or real data. Tracks realized-vs-backtest divergence as a first-class metric — a large gap means the backtest was overfit.

🏆

Improvement Log

Champion/challenger framework with a permanently frozen hold-out set. A challenger is promoted only when it genuinely beats the champion out-of-sample.

Rigor by design

Built to find honest answers

Every methodology choice is made to reduce false positives, not to make the strategy look better than it is.

✓

No lookahead — unit tested

All features are lagged ≥1 bar. Labels use only future data relative to the entry bar. A test asserts this can't be violated.

✓

Triple-barrier labeling

Profit take / stop loss / time barrier — not naive fixed-horizon returns, which introduce their own lookahead.

✓

Realistic costs every trade

8 bps round-trip (spread + slippage + commission) plus 3% annual borrow cost for shorts. Unit tested.

✓

Walk-forward with embargo

70% train / 30% test with a 5-bar embargo gap to prevent leakage through autocorrelated labels.

✓

Frozen model contract

After Tab B trains the model, it is serialized and never retrained. The simulator only calls predict(). A unit test asserts this.

✓

Benchmarked vs SPY always

Every strategy is compared to buy-and-hold SPY over the identical window. Beating zero is not the bar.

✓

Multiple-testing discipline

Promoting a challenger requires ΔSharpe > 0.15 on the permanently frozen hold-out. The multiple-testing note is always visible.

✓

Retail constraints modeled

Pattern Day Trader rule, short-borrow frictions, and the partial-data nature of free feeds are surfaced in the UI.

Get started

Zero-config setup

Requires Python 3.9+ and Node 18+. No Docker, no database server, no paid account.

01

Clone

Clone the repo from GitHub

02

Install

One command installs all deps and generates seed data

03

Run

Start backend and frontend together

04

Explore

All four tabs work immediately — no API keys

# Clone and enter the repo
git clone https://github.com/oliver139-chinesemole/edgecheck
cd edgecheck

# Install Python + Node deps, generate seed data, train default model
make install

# Start backend (:8000) + frontend (:5173)
make dev

# Run methodology tests (no lookahead, costs, frozen model)
make test

Then open http://localhost:5173

Optional API keys

Copy .env.example to .env and fill in the keys you have. Both are free-tier. The app works without them — you just see seed data instead of live data.
