Promotion Rules

  • Minimum margin: ΔSharpe > 0.15

⚠ Multiple Testing Note

Rigor by design

Built to find honest answers

Every design choice is made to reduce false positives, not to make results look better.

✓

No lookahead — unit tested

All features lagged ≥1 bar. Labels use only future data. A test asserts this can't be violated.

✓

Triple-barrier labeling

Profit take / stop loss / time barrier — not naive fixed-horizon returns, which introduce their own bias.

✓

Realistic costs every trade

8 bps round-trip (spread + slippage + commission) plus 3% annual borrow for shorts. Unit tested.

✓

Walk-forward with embargo

70% train / 30% test with a 5-bar embargo gap to prevent leakage through autocorrelated labels.

✓

Frozen model contract

After Tab B trains the model, it is serialized and never retrained. Simulator only calls predict(). Unit tested.

✓

Always benchmarked vs SPY

Every strategy is compared to buy-and-hold SPY over the identical window. Beating zero is not the bar.

✓

Multiple-testing discipline

Challenger promotion requires ΔSharpe > 0.15 on the frozen hold-out. The risk of false positives is surfaced explicitly.

✓

Retail constraints modeled

Pattern Day Trader rule, short-borrow frictions, and the partial-data nature of free feeds are surfaced in the UI.
